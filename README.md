# Brocode Barbershop – Sistem Reservasi Online

**Versi**: 2.0  
**Tanggal**: 07 November 2025  
**Platform**: HTML, CSS, JavaScript (Vanilla)  
**Penyimpanan**: Supabase

## Deskripsi Proyek
Brocode Barbershop adalah aplikasi web reservasi barbershop yang dikembangkan untuk memenuhi kebutuhan pengelolaan janji temu secara digital. Aplikasi ini menyediakan tiga role utama: **Admin**, **Pengguna (User)**, dan **Tamu (Guest)**, dengan fitur lengkap mulai dari splash screen, autentikasi, manajemen reservasi, hingga tampilan profil pengguna.

## Fitur Utama
- Splash screen animasi dengan logo dan loading premium
- Autentikasi dua level (Admin & User) 
- Admin Panel: drag & drop-to-delete, verifikasi reservasi
- User Profile: menampilkan riwayat reservasi pribadi
- Single Web Page 
- Desain responsif (mobile-first) untuk semua perangkat
- Animasi halus pada tombol, kartu, dan transisi halaman
- Auto redirect sesuai role setelah login
- Pemisahan logika melalui modul JavaScript (`main.js`)
